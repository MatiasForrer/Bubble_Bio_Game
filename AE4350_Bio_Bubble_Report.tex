\begin{abstract}
This report investigates whether a reinforcement learning agent can learn an effective scoring strategy in a custom Bubble Shooter-style computer game. The game was implemented as a Gymnasium-compatible environment with a discrete action space, a staggered hexagonal board, stochastic future bubble colours, group-clearing dynamics, floating-cluster removal, and a scrolling board. The learning agent uses Maskable Proximal Policy Optimization (Maskable PPO), so illegal board cells and physically unreachable shots are removed from the sampled action distribution. The best model selection procedure evaluates intermediate checkpoints on fixed validation seeds and stores a checkpoint whenever the average score improves. On an independent test set of 50 game episodes, the best trained agents strongly outperform a valid-random baseline. The random baseline achieves an average score of \(480.90 \pm 105.95\), while the best one-million-step checkpoint achieves \(1353.10 \pm 215.82\), with 45 wins out of 50 against random valid play. These results show that the agent learned a non-trivial policy for exploiting local colour matches and surviving longer than random play. At the same time, overlapping confidence intervals and differences between validation and test rankings show that checkpoint selection and stochastic variation must be handled carefully.
\end{abstract}

\section{Introduction}

Reinforcement learning (RL) studies agents that improve their behaviour by interacting with an environment and receiving scalar feedback. This trial-and-error structure makes it a natural member of bio-inspired intelligence: instead of solving a task from a complete analytical model, the agent adapts its policy through repeated interaction and reward feedback. Sutton and Barto describe RL as a framework in which an agent tries to maximize accumulated reward in an uncertain environment \cite{SuttonBarto2018}. The AE4350 assignment explicitly allows computer games as reinforcement learning tasks, because they provide controlled environments in which an agent perceives state, chooses actions, and receives performance feedback.

The present project implements such a task: a simplified Bubble Shooter game called \textit{Bio Bubble}. The agent observes a partly filled bubble board and the next bubble colour, then chooses a board cell in which to place the bubble. Groups of at least three connected bubbles of the same colour are removed, detached floating clusters are removed, and the board scrolls downward every second valid move. The objective is to obtain a high score while preventing bubbles from reaching the bottom row.

The central research question is:

\begin{quote}
\textit{Can a PPO-based reinforcement learning agent learn a scoring and survival strategy for a custom Bubble Shooter environment, and how sensitive is the result to training budget and model selection?}
\end{quote}

The contribution is not a new reinforcement learning algorithm. Instead, the contribution is a complete implementation and analysis pipeline: a custom game environment, action masking for legal shots, shaped rewards, automatic checkpoint evaluation, and quantitative comparison against a valid-random baseline. This is appropriate for the assignment because the rubric values a clear method, reproducible implementation, results over multiple runs, parameter sensitivity, and analysis of the learned solution.

\section{Task and Environment}

\subsection{Game Description}

The environment is a discrete single-agent game. The board has height 10 and maximum row width 8. Alternate rows are horizontally shifted and have one fewer valid cell, producing a staggered hexagonal neighbourhood pattern. Each occupied valid cell contains one of three bubble colours. Invalid padding cells are represented internally by \(-1\), empty cells by 0, and coloured bubbles by values 1--3.

At the beginning of an episode, two rows are populated at the top. At each valid step, the current bubble is placed at the selected cell and connected same-colour components are tested. A component of size three or larger is removed. After such removals, all bubbles no longer connected to the top row are considered floating and are removed as well. Every second valid move, the board scrolls downward by deleting the bottom row and adding a new stochastic row at the top. The episode terminates when a bubble reaches the bottom row, when no playable moves remain, or when the maximum round count is reached.

\subsection{State, Action and Dynamics}

The environment follows the Gymnasium interface, where an environment defines \texttt{reset()}, \texttt{step()}, action spaces and observation spaces \cite{GymnasiumEnv}. The observation is a dictionary:

\begin{itemize}
    \item \texttt{grid}: a \(10 \times 8\) integer grid with invalid, empty and coloured cells;
    \item \texttt{next\_ball}: the colour of the next bubble to be placed;
    \item \texttt{stagger\_offset}: a binary value specifying which row parity is shifted.
\end{itemize}

The action is a single discrete integer,
\[
    a = y \cdot W + x,
\]
where \(W=8\), \(x\) is the encoded column and \(y\) is the row. The environment decodes this into a candidate cell. Not all encoded actions are legal, because some cells are invalid padding cells, some are already occupied, and some are geometrically unreachable from the shooter due to blocking bubbles. The implemented action mask marks only legal target cells as available.

The state transition contains several game-specific rules. First, the agent may only place a bubble in an empty valid cell that touches the ceiling or an existing bubble. Second, the chosen target must have a clear shot path from the shooter, allowing straight shots and a limited number of wall bounces. Third, after a bubble is placed, a flood-fill operation identifies same-colour connected components using the staggered hexagonal neighbourhood. Components of size at least three are removed, followed by removal of floating components.

\subsection{Reward Design}

Two scoring systems are implemented. The human-readable score is used for reporting game performance, while the RL reward is used for learning. The human score rewards popped bubbles, floating clears, large clears, and survival. The RL reward has the same qualitative direction but smaller magnitudes and includes a game-over penalty:

\[
R =
-1
+2N_{\mathrm{pop}}
+3N_{\mathrm{float}}
+B(N_{\mathrm{pop}}+N_{\mathrm{float}})
+1.5I_{\mathrm{survive}}
-25I_{\mathrm{gameover}},
\]
where \(B(n)=6\) if \(n\geq 8\), \(B(n)=2.5\) if \(5\leq n<8\), and \(B(n)=0\) otherwise.

This reward is shaped. It does not merely indicate success or failure, but gives intermediate feedback for useful sub-goals. In this task, reward shaping is pragmatic because sparse terminal reward would make early exploration difficult: most random policies would lose before discovering large clears.

\section{Learning Method}

\subsection{Proximal Policy Optimization}

The agent is trained using Proximal Policy Optimization (PPO), a policy-gradient method introduced by Schulman et al. \cite{Schulman2017}. PPO alternates between collecting trajectories from the current policy and optimizing a clipped surrogate objective. In simplified form, the objective is
\[
L^{\mathrm{CLIP}}(\theta)
=
\mathbb{E}_{t}
\left[
\min
\left(
r_t(\theta)\hat{A}_t,\,
\mathrm{clip}(r_t(\theta),1-\epsilon,1+\epsilon)\hat{A}_t
\right)
\right],
\]
where \(r_t(\theta)\) is the probability ratio between the new and old policy, \(\hat{A}_t\) is an advantage estimate, and \(\epsilon\) limits the policy update. This clipping discourages excessively large policy updates while still permitting multiple epochs of minibatch optimization on collected data.

The implementation uses Stable-Baselines3 and SB3-Contrib. Stable-Baselines3 provides PPO hyperparameters such as learning rate, rollout length \texttt{n\_steps}, minibatch size and optimization epochs \cite{SB3PPO}. SB3-Contrib provides Maskable PPO, which extends PPO with invalid action masking \cite{SB3MaskablePPO}.

\subsection{Invalid Action Masking}

Action masking is central to this task. The encoded action space has 80 actions, but many are invalid in a given state. A standard PPO policy could spend substantial exploration probability on impossible actions. Masking sets the probability of illegal actions to zero before sampling. Huang and Ontanon analyse invalid action masking in policy-gradient algorithms and show why it is particularly useful when many actions are invalid \cite{HuangOntanon2020}.

In this implementation, \texttt{get\_action\_mask()} computes a Boolean mask over all 80 encoded actions. A cell is legal only if it is inside the current staggered row, empty, connected to the ceiling or existing bubbles, and reachable by the shot-visibility test. During training, \texttt{ActionMasker} supplies this mask to Maskable PPO. During evaluation and watching, the same mask is passed to deterministic \texttt{model.predict}.

\subsection{Checkpoint Evaluation}

A key empirical issue was that longer training did not always produce a better final saved policy. PPO is stochastic, and the final policy at the end of a run may be worse than an earlier checkpoint. To address this, the training script now performs deterministic validation every 25,000 timesteps over 10 fixed validation episodes. Whenever the validation average score improves, the current model is saved with a filename containing the total training budget, rollout length, checkpoint step and validation average score. This creates files such as:

\begin{quote}
\texttt{bubble\_pop\_model\_20260826\_122943\_ts1000000\_nsteps512\_best\_step950000\_avg1584.zip}
\end{quote}

This procedure separates two concepts: the \textit{final model}, saved at the end of training, and the \textit{best validation checkpoint}, saved at the best observed validation point.

\subsection{Evaluation Protocol}

The final reported test results use independent seeds 2000--2049, which were not used for checkpoint selection. This is important because validation checkpoints are selected using seeds 1000--1009; evaluating only on those seeds would overestimate generalization. For each model, 50 deterministic episodes were run. The random baseline was not allowed to choose invalid actions; it sampled uniformly from the valid action mask. This makes the baseline stronger and fairer than a naive random policy that wastes moves on illegal cells.

For each condition, the following statistics are reported:

\begin{itemize}
    \item mean score and 95\% confidence interval;
    \item median score;
    \item standard deviation, minimum and maximum score;
    \item mean number of survived rounds;
    \item wins out of 50 against the valid-random baseline on matching seeds.
\end{itemize}

The 95\% confidence interval is computed as
\[
\bar{x} \pm 1.96\frac{s}{\sqrt{n}},
\]
where \(\bar{x}\) is the mean score, \(s\) is the sample standard deviation and \(n=50\).

The results support the main hypothesis: Maskable PPO learns a useful policy. Even the weakest trained policy more than doubles the average score of the valid-random baseline. \section{Sensitivity Analysis}

\subsection{Training Budget}

The clearest sensitivity dimension is the number of training timesteps. Moving from 250k to the stronger 500k and 1M policies improves average test score from \(980.60\) to approximately \(1350\). The one-million-step run also produced a validation curve with continued improvement until step 950k. This indicates that the learning process had not saturated at 250k steps.

The result is not monotonic if only final policies are considered. A 500k final policy trained before checkpointing performed worse in an earlier 20-episode benchmark than the 250k model, while a later 500k final policy performed very well on the 50-episode independent test. This variation is expected in policy-gradient training, where the optimization path depends on stochastic rollouts and gradient estimates.

\subsection{Checkpoint Selection}

Checkpoint selection is a second important sensitivity. During the one-million-step run, the final model scored \(1278.50\) on the independent test, whereas the best validation checkpoint scored \(1353.10\). This is a gain of 74.60 average score points on the independent test. In the earlier 20-seed comparison, the gain from best checkpointing was even larger. Therefore, saving only the final model is not reliable enough for this task.

At the same time, the 500k best checkpoint did not outperform the strongest 500k final model on the independent test. This illustrates a normal validation-test distinction: a checkpoint selected on 10 validation episodes can overfit to those exact validation seeds. The correct conclusion is that checkpointing is useful, but final claims must still be based on independent test seeds.

\subsection{Run-to-Run Variation}

Two 500k final models trained under similar hyperparameters achieved different independent test means: \(1357.90\) and \(1109.20\). This is not a code error; it reflects the stochasticity of PPO training and the stochastic initial game boards. From a scientific reporting perspective, this means that a single training run should not be treated as a precise estimate of algorithm performance. The report therefore uses multiple evaluation episodes and confidence intervals.

\subsection{Remaining Sensitivity Limitation}

The current implementation exposes \texttt{n\_steps}, batch size, learning rate and number of epochs, but the completed long runs mainly vary training budget and model-selection strategy. A stronger final study would add at least one additional hyperparameter sweep, for example \(\texttt{n\_steps}=128\) versus \(\texttt{n\_steps}=512\), or learning rate \(10^{-4}\) versus \(3\cdot10^{-4}\). This limitation should be addressed before submission if time permits. The existing results are nevertheless sufficient to demonstrate learning, because all trained policies substantially exceed a valid-random baseline on independent seeds.

\section{Analysis of the Learned Solution}

Qualitative inspection of deterministic agent rollouts suggests that the learned policy is not merely choosing arbitrary legal positions. Compared with valid-random play, the trained policy more often places bubbles where immediate same-colour matches are possible and avoids quickly extending the board downward. It also sometimes creates or exploits floating clears, which are valuable because floating bubbles receive a larger reward than directly popped bubbles.

The learned behaviour appears mostly local and opportunistic. This is plausible because the observation contains the current grid and next bubble only; the agent cannot observe future colours beyond the next shot. The agent can therefore learn heuristics such as:

\begin{itemize}
    \item prefer placements adjacent to same-colour groups;
    \item avoid isolated placements that do not create clearing potential;
    \item maintain playable positions near the upper part of the board;
    \item exploit reachable side and wall-bounce placements when they clear bubbles.
\end{itemize}

The results support this interpretation. The trained agents survive around 25 rounds instead of 15 for the random baseline, showing improved board management. The best policies also have much higher median scores, which indicates consistent improvement rather than only rare lucky games.

The main weakness is long-horizon planning. Some episodes still end with low scores, as shown by minimum scores between 90 and 250 for the trained agents. This suggests that the learned policy can still make locally reasonable moves that later produce poor board states. A richer agent could include additional lookahead, value-based search, curriculum learning, or training with more diverse board sizes.

\section{Verification and Reproducibility}

Several implementation checks were used to reduce the chance that the result is caused by an environment bug:

\begin{itemize}
    \item smoke checks verify staggered row offsets and alternating row widths;
    \item popping tests verify same-colour group removal;
    \item floating-ball tests verify detached-cluster removal;
    \item invalid-action tests verify that illegal cells are rejected;
    \item board-shape and board-scroll tests verify stable grid dimensions;
    \item visibility tests verify that blocked targets are not marked playable.
\end{itemize}

The project can be reproduced with the following sequence:

\begin{enumerate}
    \item install the required Python packages: \texttt{gymnasium}, \texttt{stable-baselines3}, and \texttt{sb3-contrib};
    \item run smoke checks with \texttt{python smoke\_checks.py};
    \item train with the command in Section 4.1;
    \item watch the best model with \texttt{python watch\_agent.py};
    \item evaluate trained policies on held-out seeds, using deterministic predictions and action masks.
\end{enumerate}

\section{Conclusion}

This project implemented a custom Bubble Shooter environment and trained a Maskable PPO agent to play it. The environment has non-trivial discrete dynamics: staggered hexagonal adjacency, stochastic new rows, legal-shot constraints, group popping, floating-cluster removal and increasing board pressure. Action masking is essential because many encoded actions are illegal in a given state.

The trained agents clearly outperform valid-random play. On 50 independent test episodes, valid random play achieved an average score of \(480.90\), while the best trained policies achieved approximately \(1350\). The one-million-step best checkpoint won 45 out of 50 matched comparisons against random and survived roughly ten more rounds on average. The results therefore demonstrate that the agent learned a useful scoring and survival strategy.

The analysis also shows why careful reporting matters. Longer training improved the best validation checkpoint, but final checkpoints were not always best. A held-out test set was necessary because validation-selected checkpoints can rank differently out of sample. The main remaining limitation is that only a limited hyperparameter sensitivity analysis was completed. A final extension should vary rollout length or learning rate, but the current evidence is already strong enough to support the central claim: Maskable PPO can learn effective play in the implemented Bio Bubble game.
